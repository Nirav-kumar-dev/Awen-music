description:: TideFlow 1.0.1 brings smarter AI playlist queuing with radio auto-continuation, guaranteed fresh track diversity, non-blocking YouTube Music sync, MIT licensing, and updater fixes.

### What's New
- **Full AI Playlist Playback**: Tapping 'Play All' or any individual song in the AI Assistant now loads and plays the entire AI playlist seamlessly instead of single isolated tracks.
- **AiPlaylistQueue Engine**: Automatically queues all curated tracks with rich metadata and transitions smoothly into YouTube Radio recommendations once the playlist concludes.
- **Guaranteed Novelty on Every Request**: Implemented persistent AI memory tracking and variety directives so repeated or similar requests always return brand-new music discoveries.
- **Dedicated AI Agent Storage**: User profile, listening preferences, Dolby/EQ settings, and session memories are saved in persistent JSON storage (`tideflow_ai_agent_store.json`).
- **Non-Blocking YouTube Music Sync**: Replaced blocking operations with coroutine-based background syncing on startup, login, and settings toggle.
- **MIT License**: Switched project license to standard open-source MIT License.

### Bug Fixes & Improvements
- **Updater Logic Fixed**: Corrected version comparison so the app strictly requires newer releases (`isNewerVersion`), eliminating false update prompts.
- **Branding Consistency**: Unified application title, package name, and visual branding across all screens.
- **Fast AI Responses**: Optimized NVIDIA Nemotron 3.5 Lightning 30B inference with parallel track resolution.
